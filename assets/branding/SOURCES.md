# Branding sources

These PNG cards link to the profile owner's professional accounts and institutions.

- UFG: user-supplied `UFG-horizontal-white.png`, from the Desktop `lib/logos` collection.
- CEIA: https://ceia.ufg.br/wp-content/uploads/2024/10/Logo-2.png
- LinkedIn: Devicon v2.17.0, https://github.com/devicons/devicon/blob/v2.17.0/icons/linkedin/linkedin-original.svg
- ORCID: Simple Icons, https://github.com/simple-icons/simple-icons/blob/develop/icons/orcid.svg ; rendered in the ORCID brand green.
- Plataforma Lattes: https://ppgpmbqbm.ufms.br/files/2017/08/Lattes-CNPq-logo.jpg
- Email: generic envelope icon drawn as SVG, then rendered as PNG.

The logos retain their proportions. The surrounding cards are layout elements for the GitHub profile. Brand names and marks belong to their respective owners.
